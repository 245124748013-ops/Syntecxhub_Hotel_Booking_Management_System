# Hotel Booking Management System

A simple console-based Hotel Booking Management System developed in Java as part of my Syntecxhub Java Programming Internship.

## Features

- View available hotel rooms.
- Book a room by entering the room number and guest name.
- Cancel an existing booking.
- View the status of all rooms and guest names.
- Validate user input and handle invalid room numbers and menu choices.
- Display room availability and total available rooms.

## Technologies Used

- Java
- Java Scanner for user input
- Arrays for storing room booking information
- Command-line interface (CLI)

## Requirements

- Java Development Kit (JDK) installed.
- Terminal or command prompt.

## How to Run

1. Download or clone this repository.
2. Open a terminal in the `src` folder containing `HotelBookingManagementSystem.java`.
3. Compile the Java program:

   ```bash
   javac HotelBookingManagementSystem.java
   ```

4. Run the program:

   ```bash
   java HotelBookingManagementSystem
   ```
